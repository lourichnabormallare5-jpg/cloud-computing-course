# Cloud Computing Concepts Reflection

Cloud computing has become an important part of my daily life because many of the applications I use depend on cloud services. Three cloud services that I regularly use are Google Drive, Facebook Messenger, and Canva.

Google Drive is an example of Software as a Service (SaaS) because it allows users to store, edit, and share files through a web browser without installing complex software. It is deployed using the Public Cloud because anyone with an internet connection and a Google account can access the service.

Facebook Messenger is also a Software as a Service (SaaS). It provides instant messaging, voice calls, and video calls through cloud-based servers. Like Google Drive, Messenger uses the Public Cloud since it serves millions of users over the internet.

Canva is another Software as a Service (SaaS) application. It allows users to create presentations, posters, and graphics online without installing professional design software. Canva also operates on the Public Cloud because it is available to users worldwide through an internet connection.

Version control is essential when developing cloud-based applications and infrastructure because it records every change made to files and configurations. If mistakes occur, developers can restore previous versions quickly. Git helps track changes efficiently, while GitHub provides a central platform where team members can collaborate, review code, and manage projects. Features such as branches, pull requests, and commit history reduce conflicts and improve teamwork. Using GitHub also makes it easier to organize documentation, laboratory activities, and cloud projects in one place. Overall, cloud computing and version control work together to improve productivity, collaboration, and reliability in modern software development.
